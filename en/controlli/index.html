Missing care checks

An AI agent read the record of every invented patient using read-only tools, and proposes the missing checks according to five example rules (not guidelines). Every proposal cites the data it rests on; a verifier written in code re-checks every claim before it gets here. The clinician decides.

How reliable it is

On 50 patients it found 13 missing checks out of 14, with 0 false alarms. The verifier blocked 8 unproven claims out of 247.

What it teaches

When the agent sees only the data extracted from three notes per patient, it finds 2 of 14: the notes tell the latest episodes, not the list of chronic problems. An agent is worth the data it sees.
